# Vibrant B2B showcase design

## Мета та характер

Створюй **сміливу, професійну B2B-вітрину**, а не надмірно декоративний або інфантильний інтерфейс. Вона має викликати довіру в покупця чи замовника через повітря, чітку ієрархію, конкретні параметри та великі фото реального продукту або реалізованих об’єктів. Відчуття енергії походить із контрасту кольорів і великих округлих форм, а не з кліпарту, конфеті чи беззмістовного декору.

Базова формула: теплий майже-білий фон + чорна типографіка + один сильний помаранчевий CTA + сині/жовті/темні акцентні площини + реальна фотографія з затемнювальним градієнтом, коли текст лежить поверх фото.

## Токени

Це референсна палітра для цього напряму. Якщо в продукті вже є затверджені дизайн-токени, збережи їхні ролі та контраст, а не дослівно замінюй палітру. Не вводь випадкові пастельні відтінки.

| Роль | Значення | Застосування |
| --- | --- | --- |
| Поверхня сторінки | `#FFFEF5` | головний фон |
| Основний текст / темна поверхня | `#141210` | текст, темні секції, footer |
| Картка | `#FFFFFF` | картки та форми |
| М’яка поверхня | `#F2EDE0` | фони полів, вторинні кнопки, спокійні секції |
| Основний CTA | `#FF4500` | головна дія, активний стан, навігаційний індикатор |
| Вторинний акцент | `#0055FF` | CTA-банери та одна з акцентних площин |
| Яскравий акцент | `#FFD700` | бейджі, контрастна дія на синьому/темному тлі |
| Допоміжний текст | `#6B6050` | описи та другорядні дані |
| Межа | `rgba(20, 18, 16, 0.12)` | тонкі контури карток |

- Основний шрифт: `Inter`, 400–700, для тексту інтерфейсу.
- Дисплейний шрифт: `Unbounded`, 600–900, для `h1–h3`, великих чисел і ключових назв продуктів. Якщо цей шрифт не доступний або не узгоджується з наявним продуктом, обери інший геометричний display sans із подібною щільністю.
- Заголовки: щільний трекінг, `line-height: 1.1`; на великих екранах `h1` 60px, секційний заголовок 48–50px, на мобільних — 36–40px.
- Надзаголовки: 12px, semibold, uppercase, помаранчеві, з виразним letter-spacing. Це стабільний маркер початку секції.
- Базовий радіус — 16px. Використовуй 12px для кнопок і полів, 16–24px для карток, 24px для великих панелей/банерів. Не використовуй гострі прямокутники в основному UI.

## Композиція сторінки

- Контейнер: `max-width: 1280px` (`max-w-7xl`), горизонтальні відступи 24px; у hero допустимі 32px на мобільному та 64px на desktop.
- Звичайні секції мають вертикальний ритм 80–96px; великі проміжки між їхнім заголовком і контентом — 48–56px.
- Hero на desktop — дві рівні колонки: текст ліворуч, фото праворуч. Текстова частина містить жовтий бейдж, дисплейний заголовок із помаранчевим виділенням одного смислового рядка, короткий опис, primary і secondary CTA, два числові докази. Фото займає висоту екрана; поверх нього допустима компактна напівпрозора картка з рейтингом/відгуком.
- Чергуй світлі секції з кольоровими площинами. Темна `#141210` секція працює для портфоліо, довіри або фінального контрасту; синя — для сильного CTA; жовта — для таймлайну чи швидкого пояснення.
- Не перетворюй усе на картки: фонові площини, повноширинні медіа та прості колонки повинні врівноважувати card UI.

## Повторювані компоненти

### Верхня навігація

- Тонкий info bar може бути над основним nav.
- Основний nav фіксований, білий/тепло-білий із 95% непрозорістю, backdrop blur, тонкою нижньою межею та м’якою тінню.
- Логотип або словесний знак лишається таким, яким його визначає продукт. Не вигадуй монограму, назву чи кольорове виділення частини назви.
- Активний пункт — помаранчевий текст із короткою помаранчевою рискою знизу. На mobile — меню, що розкривається під навігацією; активний пункт має помаранчевий індикатор і дуже світлий помаранчевий фон.

### Кнопки, фільтри, бейджі

- Primary: помаранчева заливка, білий semibold текст, радіус 12px, висота близько 48–56px; на hover — трохи темніший помаранчевий або зниження opacity.
- Secondary: `#F2EDE0`, темний текст. На темному або синьому блоці secondary може бути білою.
- Жовта кнопка призначена для дії на темно-синій/темній поверхні; текст завжди темний.
- Фільтри — компактні pill-кнопки. Обраний стан має суцільну primary-заливку, не лише обведення. Категорії можуть отримувати власний колір у активному стані.
- Бейджі — маленькі, жирні, `rounded-full`; кольоровий бейдж для типу/категорії, білий напівпрозорий для другорядних тегів на фото, muted для метаданих.

### Картки та медіа

- Каталожна картка: біла, тонка межа, радіус 24px, фото у пропорції 4:3, кольоровий бейдж категорії поверх фото, 20px padding у текстовій частині. На hover: ледь сильніша тінь, border з помаранчевим відтінком, фото масштабується до `1.05` за ~500ms.
- Картка категорії: фото — весь фон, `aspect-ratio: 4/3`, темний градієнт знизу, білий заголовок і короткий опис внизу. Не став текст на незатемнене фото.
- Картка кейсу: медіа 16:10, поверх — категорія, країна/рік, внизу назва; нижче — 2–3 короткі факти (локація, площа, клієнт). Вона продає конкретним доказом, не абстрактною «історією успіху».
- Великі media-блоки й галереї використовують `object-fit: cover`; зберігай видимість важливої частини фото через явний `object-position`, якщо це потрібно.
- Усі обкладинки мають hover-ефект збільшення, а текстові посилання з іконкою стрілки — невеликий рух стрілки вправо. Анімації короткі, без пружного/іграшкового характеру.

### Інформація, форми, довіра

- Характеристики показуй у приглушеній панелі `#F2EDE0`, двоколонковою сіткою: small muted label над чітким значенням. Це важливіше за декоративні іконки.
- Панель відгуку — темна, велика, із жовтими зірками та білим текстом; одна акцентна testimonial-картка у ряду може бути помаранчевою.
- Поля форми мають `#F2EDE0` фон, радіус 12px, без важкої рамки; label — дрібний uppercase muted. Focus ring — помаранчевий.
- Показуй вимірювані докази: м², кількість проєктів, країни, терміни, сертифікати. Сертифікати — компактні outline pills у footer або блоці довіри.

## Сітки та адаптивність

- Типові desktop-сітки: категорії 3 колонки, продукти 3, кейси 3, переваги 4, процес 3, галерея 4 з одним hero-tile на 2×2.
- На tablet переходь до 2 колонок; на вузькому екрані — до 1 колонки. Виняток: короткі категорії або фотогалерея можуть лишатись у 2 колонках.
- Catalog: desktop — sticky sidebar шириною близько 224px; mobile — кнопка Filters та розкривна двоколонкова панель. Не стискай sidebar в горизонтальний скрол.
- Detail pages: desktop — медіа й опис у 2 колонки; для кейсу — контент 2/3 плюс sticky info card 1/3. На mobile спочатку медіа, потім весь текст і CTA; sticky скасовується.
- Дії мають лишатись доступними пальцем: мінімум 44px висоти, видимий focus state, достатній контраст тексту на яскравих кольорах.

## Обмеження якості

- Використовуй реальні або правдоподібні фото просторів та атракціонів, а не кліпарт, cartoon-ілюстрації чи штучні декоративні патерни. Фотографія — головний носій емоції.
- За раз виділяй один головний CTA. Primary-колір не має бути фоном кожного блоку; його сила — у вибірковому використанні.
- Для одного кольорового блоку тримай не більше одного основного акцентного кольору та одного контрастного кольору для CTA/бейджа.
- Не додавай градієнти як самостійний брендовий ефект: вони призначені лише для читабельності тексту поверх фотографії.
- Не копіюй вигадані цифри, сертифікати, відгуки, адреси чи соціальні посилання з референсу. Під час реалізації використовуй лише дані, надані проєктом, або нейтральні заповнювачі, чітко позначені для заміни.

## Перед завершенням

Перевір, що сторінка має достатньо повітря, ієрархія читається без кольору, primary CTA один на контекст, фото не робить текст нечитабельним, а mobile не є просто зменшеною desktop-сіткою. Переконайся, що Unbounded застосовано лише як акцентний display-шрифт, а не до всіх абзаців.
